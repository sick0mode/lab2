\# Python Calculator



Небольшой учебный проект на языке Python, созданный для выполнения лабораторной работы по изучению Git, GitFlow, GitHub Desktop, GitHub и GitHub Actions.



\## Возможности



Программа поддерживает базовые математические операции:



\- сложение;

\- вычитание;

\- умножение;

\- деление;

\- проверку числа на чётность;

\- возведение числа в степень.



\## Структура проекта



\- `main.py` — основной файл программы и взаимодействие с пользователем;

\- `calculator.py` — функции для выполнения вычислений;

\- `test\_calculator.py` — автоматические тесты;

\- `.gitignore` — список файлов и папок, которые не должны попадать в репозиторий.



\## Запуск проекта



Для запуска программы необходимо выполнить команду:
